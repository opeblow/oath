# Code of Conduct

## Our pledge

We want OATH to be a welcoming project for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback.
- Focus on what is best for users and the project.

## Unacceptable behaviour

- Harassment, insults or personal attacks.
- Sexualised language or imagery.
- Publishing someone's private information without permission.
- Promoting scams, pump schemes or shilling in project spaces.

## Enforcement

Report problems to the maintainer through a private message on GitHub (@opeblow). Reports are kept confidential. Maintainers may remove comments, commits or contributors that break this code.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
